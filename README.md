# evpsy

Сайт-визитка психолога на `Next.js`.

## Локальная разработка

```bash
npm install
npm run dev
```

Сайт будет доступен на `http://localhost:3000`.

## Статическая сборка

```bash
npm run build
```

После сборки готовый статический сайт находится в каталоге `out/`.

## Локальная проверка статической сборки

```bash
npm run serve:static
```

После запуска статическая версия сайта будет доступна на `http://localhost:3000`.

То же самое через `make`:

```bash
make build
make serve
```

Или одной командой:

```bash
make preview
```

## Деплой

Для деплоя достаточно:

- выполнить `npm run build`
- скопировать содержимое `out/` на сервер
- раздавать статику любым веб-сервером

## Замечания

- В рантайме `Node.js` не нужен, он используется только на этапе сборки.
- Проект настроен как статический export через `Next.js`.
